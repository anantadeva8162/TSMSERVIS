CARA MEMASANG:
1. Buka Google Spreadsheet Anda.
2. Pilih Extensions > Apps Script.
3. Hapus kode lama jika ada.
4. Masukkan isi Code.gs dari ZIP ini ke file Code.gs.
5. Buat file HTML bernama Index.
6. Masukkan isi Index.html ke file tersebut.
7. Klik Save.
8. Pilih Deploy > New deployment.
9. Pilih Type: Web app.
10. Execute as: Me.
11. Who has access: Anyone.
12. Klik Deploy.
13. Izinkan akses Google jika diminta.
14. Salin Web app URL yang diberikan Google.

CATATAN:
- Tidak memerlukan script.js terpisah.
- Sheet bernama "Data" akan dibuat otomatis jika belum ada.
- Header spreadsheet dibuat otomatis.
- Form tetap menyimpan data ke spreadsheet ID di atas.
- Jika Anda sudah memiliki deployment lama, setelah mengganti kode lakukan
  Deploy > Manage deployments > Edit > New version > Deploy.
